## [0.1.0] - 2026-10-23

### Added

- Independent application shell and open-source governance.
- Reusable booking workflow with synthetic configuration and explicit demo mode.
- Optional Supabase adapter and insert-only RLS schema example.
- Developer onboarding, architecture, starter and deployment guides.
- CI validation, booking unit tests, CodeQL and Dependabot.
- Personal brand and course landing presentation examples.
- In-memory CRM and admin dashboard patterns, and local order collection.
- Eleven unit/adapter tests and twelve desktop/mobile Chromium browser checks.
- Markdown link validation and CI browser report artifacts.

### Fixed

- Dashboard cards now contain wide tables on mobile without page overflow.

### Security

- Upgraded inherited dependencies to available compatible fixes.
- Documented unresolved development-only braces advisory in SECURITY.md and issue #11.

### Limitations

- Examples are not production systems: authentication, payments, atomic booking,
  server-authoritative pricing and live Supabase RLS verification remain roadmap work.
