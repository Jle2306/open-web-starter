# Roadmap

Checkboxes describe implemented work, not promises or usage metrics.

## Phase 1 — OSS Foundation

- [x] Independent application shell and public repository
- [x] MIT license, contribution/security policies and issue/PR templates
- [x] Complete developer documentation and v0.1.0 release preparation

## Phase 2 — Starter Extraction

- [x] Booking workflow with reusable configuration and explicit demo mode
- [x] Lightweight CRM with synthetic records
- [x] Reusable administration patterns
- [x] Creator, course landing and order collection examples

## Phase 3 — Data Layer

- [x] Optional Supabase adapter and least-privilege schema example
- [ ] Verify policies against a disposable Supabase instance
- [ ] Authenticated tenant access and server-side validation
- [ ] Atomic availability and server-authoritative order pricing

## Phase 4 — Testing & Quality

- [x] Initial lint, TypeScript and build workflow
- [x] CodeQL and dependency monitoring
- [x] Browser E2E automation for booking failures and retries
- [ ] Automated accessibility coverage
- [ ] Resolve development-only upstream braces advisory

## Phase 5 — Developer Experience

- [x] Getting-started, architecture, deployment and extraction guides
- [ ] Independent starter packaging based on real usage needs

## Phase 6 — Community

- [x] Prepare v0.1.0 with documented checks and release notes
- Publication status is recorded in [GitHub Releases](https://github.com/Jle2306/open-web-starter/releases).
- [ ] Review incoming contributions and reproducible feedback
- [ ] Document third-party usage only when verifiable and shared with permission
