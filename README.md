# Open Web Starter

Reusable open-source Next.js starters for personal brands,
local businesses, independent developers, students and small teams.

Initial application shell. Starter extraction and contributor documentation are in progress.

## Run locally

Requires Node.js 24 and npm. Run `npm ci`, then `npm run dev`.
Open http://localhost:3000. Run `npm run lint`, `npm run typecheck` and `npm run build` to validate.
